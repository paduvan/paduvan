# Ronald Benny Paduvan

MSc Product Development, Chalmers University of Technology (2024–2026).
Master's thesis at RISE Research Institutes of Sweden on **Metal Binder Jetting (MBJ) of 316L stainless steel**: how sintering temperature (1250–1310 °C) and hot isostatic pressing (HIP) affect densification and porosity, and which design rules keep thin, unsupported features printable.

### What I built for the thesis
- **LOM pore-analysis tool**: web app for micrograph thresholding with live preview, binary pore masks, area fraction, pore counts and pore-shape classes, with plots and Excel output.
- **Image pipeline**: Fiji (ImageJ) + Python batch processing of light-optical micrographs into pore masks, with per-image pixel size and a live progress monitor.
- **Analysis web suite**: local dashboards for Archimedes density, stereology, porosity maps and a figure gallery.
- **Report tools**: thesis page/figure/table statistics, Overleaf image audit and slimming, image downsizing for print, text-similarity check against the literature.
- **3D and presentation automation**: STL/GLB model generation and scripted PowerPoint slides and animations.
