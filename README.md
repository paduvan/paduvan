# Ronald Benny Paduvan

MSc Product Development, Chalmers University of Technology (2024–2026).
Master's thesis at RISE Research Institutes of Sweden on **Metal Binder Jetting (MBJ) of 316L stainless steel**: how sintering temperature (1250–1310 °C) and hot isostatic pressing (HIP) affect densification and porosity, and which design rules keep thin, unsupported features printable.

### Master's thesis tools
- **lom-pore-analysis** — web app for pore segmentation, area fraction, pore counts and M1–M4 pore-shape classes in optical micrographs.
- **mbj-316l-densification-analysis** — the thesis analysis pipeline: Fiji + Python mask pipeline, Archimedes density, pore morphology, sintering vs HIP statistics, sag-bridge design study.
- **mbj-thesis-latex** · **simufact-mbj-sintering-sim** — thesis source and simulation notes.

### Personal tools
- **thesis-report-tools** — four local web tools for writing a thesis: content statistics of a thesis PDF, Overleaf image audit and slim copy, print-size image downsizer, offline PDF toolkit.
